## Descripción

Pixel Snake es un proyecto personal creado con Godot Engine para aprender a utilizar el motor para futuros proyectos.

El juego cuenta con multiples configuraciones para el gameplay y la dificultad de este, además de configuraciones para la apariencia y el apartado visual, manteniendo el estilo clásico de movimiento con cuadriculas y sprites pixel-art que se adaptan a la forma de la serpiente.

## Instalación

Puedes descargar la ultima versión ejecutable del juego directamente desde el apartado de **[Releases](https://github.com/iTzFireFoxX/Pixel-Snake/releases)** para Windows y para Linux.

Si deseas explorar el codigo fuente clona el repositorio con el siguiente comando:

```
git clone https://github.com/iTzFireFoxX/Pixel-Snake.git
```

Luego importa el proyecto desde Godot Engine seleccionando el archivo `project.godot`.

Ten en cuenta que el proyecto actualmente esta siendo desarrollado en Godot Engine 4.7, aunque es posible que funcione sin problemas en versiones anteriores o posteriores del motor.
